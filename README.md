## About This Project

Coming from a background in **Security Operations (SOC)**, some of the most common issues I see during access reviews are orphaned accounts, missing MFA configurations, and privilege creep when employees go on a long leave of absence or change departments.

I built this laboratory while preparing for the **Microsoft AZ-104** and **SC-300** certifications to translate daily identity governance controls into **PowerShell** scripts using the **Microsoft Graph API**.

---

## Phase 1: Cloud IAM & Hygiene Automation (Completed)

### 1. Joiner-Mover-Leaver (JML) & RBAC Provisioning (`New-JMLProvisioning.ps1`)

Reads a made up Human Resources CSV feed and reconciles user accounts and Role-Based Access Control (RBAC) security groups in Microsoft Entra ID:

- **Joiner (Onboarding):** Creates new users with temporary passwords (`ForceChangePasswordNextSignIn`), sets organizational attributes (`EmployeeId`, `Department`, `JobTitle`), and assigns baseline + departmental RBAC security groups.
- **Mover (Role Change):** Detects department or job title changes, updates user attributes, assigns the new departmental security group, and **removes previous departmental groups** to prevent privilege accumulation (_Privilege Creep_).
- **Leaver (Offboarding):** Disables user sign-in (`AccountEnabled = $false`), immediately revokes active refresh tokens and sessions (`Revoke-MgUserSignInSession`), and removes all security group memberships.
- **Operational Features:** Supports a `-DryRun` simulation mode for safe testing and outputs structured `.jsonl` audit logs ready for SIEM ingestion.

### 2. Identity Hygiene & Access Review Audit (`Invoke-IdentityHygieneAudit.ps1`)

Audits the Entra ID tenant to generate compliance reports (`.csv` and `.json`) covering three foundational security controls:

- **Inactive Accounts (>90 Days):** Checks both interactive (`LastSignInDateTime`) and non-interactive (`LastNonInteractiveSignInDateTime`) sign-in logs to identify dormant enabled accounts without generating false positives for background sessions.
- **MFA Registration Status:** Queries the Microsoft Graph Authentication Methods report (`Get-MgReportAuthenticationMethodUserRegistrationDetail`) to detect enabled users without registered MFA methods.
- **Standing Privileged Access:** Reviews permanent active memberships across critical directory roles (_Global Administrator, Security Administrator, Privileged Role Administrator, User Administrator, Application Administrator_).
